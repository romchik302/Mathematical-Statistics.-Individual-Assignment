# Математическая статистика — индивидуальное задание

Решение индивидуального задания по курсу **математической статистики**: моделирование выборок, точечные и интервальные оценки, критерий согласия Пирсона, проверка независимости и эмпирические линии регрессии.

Репозиторий содержит скриптовый запуск (`main.py` + `tasks.py`) и развёрнутое решение в Jupyter-ноутбуке (`main.ipynb`). Пояснительная записка — файл `пояс записка.docx`.

## Содержание работы

| Задание | Распределение | Что делается |
| --- | --- | --- |
| 1 | Нормальное \(N(0{,}9;\; 12{,}96)\), \(n = 475\) | Гистограмма, оценки параметров, ДИ при \(\gamma = 0{,}95\), критерий \(\chi^2\) при \(\alpha = 0{,}05\) |
| 2 | Показательное с параметром \(a = 1{,}5\), \(n = 400\) | Гистограмма, метод моментов, ДИ при \(\gamma = 0{,}99\), критерий \(\chi^2\) при \(\alpha = 0{,}001\) |
| 3 | Двумерное нормальное, \(n = 475\), \(r = -0{,}43\) | Оценки параметров, проверка независимости, уравнения регрессии \(Y\) на \(X\) и \(X\) на \(Y\) |

Параметры выборок соответствуют варианту задания.

## Структура репозитория

```
├── main.py              # запуск всех трёх заданий
├── tasks.py             # реализация расчётов, графиков и таблиц
├── main.ipynb           # то же решение в виде ноутбука
├── requirements.txt
├── пояс записка.docx    # пояснительная записка
└── README.md
```

При запуске скрипта в рабочей директории появляются:

- графики `task1_hist.png`, `task2_hist.png`, `task3_regression.png`;
- таблицы Excel `table_1_1.xlsx`, `table_1_5.xlsx`, `table_2_1.xlsx`, `table_2_5.xlsx`, `table_3_1.xlsx`, `table_3_2_contingency.xlsx`.

## Требования

- Python 3.10+
- пакеты из `requirements.txt`

## Установка и запуск

```bash
python -m venv .venv
```

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Linux / macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Ноутбук:

```bash
jupyter notebook main.ipynb
```

Для воспроизводимости в `tasks.py` зафиксирован `numpy`-seed (`42`).

## Примечание по графикам

Скрипт сохраняет рисунки в PNG и вызывает `plt.show()`. Если окно с графиком не нужно, задайте неинтерактивный backend.

PowerShell:

```powershell
$env:MPLBACKEND = "Agg"
python main.py
```

cmd / Linux / macOS:

```bash
set MPLBACKEND=Agg
python main.py
```
